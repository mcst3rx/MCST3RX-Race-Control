# 🏁 MCST3RX Race Control

**Race Control. Your Way.**

MCST3RX Race Control is an independent Windows x64 gameplay companion for NASCAR 25 and NASCAR 26. It provides per-game options, configurable hotkeys, and game selection for supported offline sessions.

> **Latest published release:** v1.1.0  
> **In development:** v1.2.0, pending gameplay qualification and release approval

---

## 📥 Download

Download the Windows x64 ZIP from the [v1.1.0 release](https://github.com/mcst3rx/MCST3RX-Race-Control/releases/tag/v1.1.0). Compare its SHA-256 with the checksum supplied alongside the release asset. The [releases page](https://github.com/mcst3rx/MCST3RX-Race-Control/releases) also retains v1.0.0.

## 🎮 Supported games and features

The published v1.1.0 package was historically accepted with 19 NASCAR 25 options and 16 NASCAR 26 options. See its [release notes](RELEASE_NOTES.md) for the feature and hotkey tables. Availability depends on the game build and session context.

| v1.2.0 development status | Scope |
|---|---|
| Historically accepted Race Control routes | 19 NASCAR 25 and 14 NASCAR 26 routes retained for current-build testing |
| Conditional qualification | NASCAR 26 Work Points and R&D Points require verification of the selected Career wallet and gameplay behavior |
| Execution gated | NASCAR 26 Easy AI, Super Acceleration, Super Brakes, and Super Jump |

The v1.2.0 catalog has 39 entries across both games. Independent gameplay acceptance on the final build is pending. v1.1.0 is the current download.

## 🚀 Installing and getting started

1. Extract the release ZIP and keep its files together.
2. Start Race Control and select your game.
3. Use an offline single-player session. Career editors require the selected Career context. Vehicle and timing options require the applicable on-track session.
4. Review each option's status before use. Disconnect if the game build or session is refused.
