# 🏁 MCST3RX Race Control v1.1.0

**Race Control. Your Way.**

Windows x64: **NASCAR 25 — 19 supported/live-accepted options** and **NASCAR 26 — 16 supported/live-accepted options**.

## 📥 Download & Usage

Download the Windows ZIP from the official [v1.1.0 release](https://github.com/mcst3rx/MCST3RX-Race-Control/releases/tag/v1.1.0). Extract it and keep the executable and runtime DLLs together. Start your game normally, select the game in Race Control, and Connect. Use **Disconnect / restore** before switching games or exiting.

See the [release notes](RELEASE_NOTES.md) for all hotkeys, usage and limitations, and [SHA256SUMS.txt](SHA256SUMS.txt) to verify the download. Use offline sessions; saved progression edits may persist. Game updates may require compatibility updates.

## ✨ Current Game Support

**NASCAR 25:** 19 supported options, including Edit RD Points. Its accepted implementation remains unchanged.

**NASCAR 26:** 16 supported options:

1. Edit Money
2. Edit Work Points
3. Edit REP Points
4. Edit RD Points
5. Unlimited Fuel
6. Max Aero Condition
7. Max Engine Condition
8. Max Radiator Condition
9. Max Tire Condition
10. Optimal Oil / Water Temp
11. Edit Tire Temperature
12. Edit Grip Rate
13. Ghost Mode
14. Increase Lap Time
15. Decrease Lap Time
16. Edit Laps

Easy AI, Super Acceleration, Super Brakes and Super Jump remain **unreleased for NASCAR 26**. This release does not claim NASCAR 26 20/20; their NASCAR 25 counterparts remain supported.

## 💬 Bug Reports & Feature Requests

Found a problem with MCST3RX Race Control or have an idea for an improvement?

➡️ **Open an Issue:**  
https://github.com/mcst3rx/MCST3RX-Race-Control/issues/new/choose

Choose the appropriate template:

- 🐛 **Bug Report** — Report a problem or something that is not working as expected.
- 💡 **Feature Request** — Suggest a new feature, improvement, or workflow.

### 🐛 Bug Reports

Before submitting a bug report:

- Make sure you are using the latest official release.
- Check existing issues to see whether the problem has already been reported.
- Include your MCST3RX Race Control version.
- Include the affected game and game version/build when known.
- Identify the affected feature or area.
- Explain the exact steps needed to reproduce the problem.
- Include any relevant status or error message.
- Attach screenshots or a short recording when useful.
- Do not publicly upload passwords, credentials, or other sensitive information.

> **NASCAR 26:** v1.1.0 supports the 16 options listed above. Report issues with these released features using the instructions above.

### 💡 Feature Requests

Before submitting a feature request:

- Check existing issues to see whether the idea has already been suggested.
- Submit one feature request per issue.
- Include your current Race Control version.
- Clearly describe the feature or improvement.
- Explain why it would be useful.
- Describe how you imagine it working.
- Include screenshots, mockups, examples, or references when helpful.

Feature requests are suggestions and are not guaranteed to be implemented.

> **NASCAR 26:** Requests for additional features are welcome. The four unreleased physics features are not part of v1.1.0; no completion date is promised.
