# 🏁 MCST3RX Race Control

**Race Control. Your Way.**

A Windows x64 companion tool for NASCAR 25 and NASCAR 26, featuring convenient hotkeys, game selection, connection management and offline gameplay options.

**Latest official release: v1.1.0**

**NASCAR 25 — 19 supported options | NASCAR 26 — 16 supported options**

MCST3RX Race Control v1.2.0 is in development, targeting 19/19 NASCAR 25 features and 20/20 NASCAR 26 features.

The v1.2.0 release will become available after final feature validation and gameplay acceptance.

## 📥 Download & Usage

Download the latest official Windows ZIP:

**[MCST3RX Race Control v1.1.0 — Download](https://github.com/mcst3rx/MCST3RX-Race-Control/releases/tag/v1.1.0)**

Extract the ZIP and keep the executable and required runtime DLLs together.

To use Race Control:

1. Launch NASCAR 25 or NASCAR 26 normally.
2. Open MCST3RX Race Control.
3. Select the appropriate game.
4. Choose **Connect**.
5. Use the available options and their assigned hotkeys.
6. Choose **Disconnect / restore** before switching games or exiting.

See [Release Notes](RELEASE_NOTES.md) for hotkeys, usage instructions and known limitations.

Use [SHA256SUMS.txt](SHA256SUMS.txt) to verify your downloaded release.

**Important:** Race Control is intended for offline gameplay. Saved progression changes may persist. Game updates may require compatibility updates.

## 💬 Bug Reports & Feature Requests

Found a problem with MCST3RX Race Control or have an idea for an improvement?

**[Open an Issue](https://github.com/mcst3rx/MCST3RX-Race-Control/issues/new/choose)**

Choose the appropriate template:

- 🐛 **Bug Report** — Report a problem or something that is not working as expected.
- 💡 **Feature Request** — Suggest a new feature, improvement or workflow.

### 🐛 Bug Reports

Before submitting a bug report:

- Make sure you're using the latest official release.
- Check existing issues for similar reports.
- Include your MCST3RX Race Control version.
- Include the affected NASCAR game and game version/build, if known.
- Identify the affected feature.
- Describe the steps needed to reproduce the issue.
- Include relevant status messages or screenshots.
- Attach a short recording if it helps explain the problem.
- Do not share passwords, credentials, save files containing sensitive information or private system data.

**NASCAR 26:** When reporting issues with Work Points or RD Points, include the selected Career series and relevant status messages, but do not post private diagnostic data.

### 💡 Feature Requests

Before submitting a feature request:

- Check whether the idea has already been suggested.
- Submit one feature request per issue.
- Include your current Race Control version.
- Describe the proposed feature clearly.
- Explain how it would improve your experience.
- Include screenshots, mockups or examples when useful.

Feature requests are suggestions and are not guaranteed to be implemented.
