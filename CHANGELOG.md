# Changelog

## v1.1.0 — 19 NASCAR 25 / 16 NASCAR 26 options

- NASCAR 25: 19 supported options, including Edit RD Points.
- NASCAR 26: 16 supported options; full list in RELEASE_NOTES.md.
- Per-game catalogs/hotkeys and switching; Fuel lifecycle and Ghost corrections retained.
- UI column/header alignment and clean editor help; 100%, 150%, 200% DPI checks.
- 2,257 checks passed; exact binary subsequently accepted in live testing.
- Four additional NASCAR 26 physics features remain unreleased. No N26 20/20 claim.

## v1.0.0 — Initial public release

- Initial MCST3RX Race Control release for NASCAR 25 on Windows x64.
- 18 gameplay options with 18 hotkeys and six live value editors.
- Compact native racing-themed interface with clear feature states.
- Connect and Disconnect / restore workflow.
- Enable/disable audio feedback with Mute control.
- YouTube, Ko-fi, Discord and GitHub community links.

NASCAR 26 is future / not yet supported. Game updates may affect compatibility.
