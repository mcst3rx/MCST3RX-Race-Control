# Changelog

## v1.0.0 — Initial public release

- Initial MCST3RX Race Control release for NASCAR 25 on Windows x64.
- 18 gameplay options with 18 hotkeys and six live value editors.
- Compact native racing-themed interface with clear feature states.
- Connect and Disconnect / restore workflow.
- Enable/disable audio feedback with Mute control.
- YouTube, Ko-fi, Discord and GitHub community links.

NASCAR 26 is future / not yet supported. Game updates may affect compatibility.
